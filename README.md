# verify-fin
 This project proposes VERIFY-FIN, a novel multi-agent framework for financial data analysis that introduces claim-level grounding as a first-class architectural component. In VERIFY-FIN, each analyst agent is constrained to produce structured outputs explicit claim objects with an associated source reference and confidence estimate —rather than free-form prose. A dedicated Verification Agent then retrieves the cited source from a Retrieval-Augmented Generation (RAG) knowledge base (populated from SEC EDGAR filings, FRED macroeconomic data, and financial news feeds) and computes a grounding score for each claim. Claims that fall below a grounding threshold are either flagged, challenged by a Debate Agent, or blocked from reaching the final Synthesis Agent. The resulting report is a fully traceable, citation-backed analysis document with measurably reduced hallucination rates.
